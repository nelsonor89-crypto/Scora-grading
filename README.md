# CodeAI Hub — IAs gratuitas para programar

Directorio web estático con las mejores herramientas de inteligencia artificial para programar, **100 % gratuitas**.

## Estructura

```
index.html   — Página principal
styles.css   — Estilos (tema oscuro, responsive)
app.js       — Búsqueda + filtros en tiempo real
```

## Funcionalidades

- **18 herramientas** en 6 categorías: Chat IA, Copiloto IDE, Autocompletado/API, Revisión/Debug, Agentes Autónomos y Aprendizaje
- Búsqueda en tiempo real por nombre, lenguaje o etiqueta
- Filtros por categoría
- Tabla comparativa rápida
- Guía "¿cuál elegir?" según perfil del usuario
- Diseño responsive (mobile-first)
- Sin dependencias externas — solo HTML + CSS + JS vanilla

## Uso

Abre `index.html` directamente en el navegador o despliega en cualquier hosting estático (GitHub Pages, Netlify, Vercel, etc.).
